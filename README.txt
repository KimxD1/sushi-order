(사용설명서)
🍣 꼬마 초밥집 주문 시스템 — 사용설명서 (간단 버전)
==================================================

[ 구성 ] 태블릿 5대
  테이블 1 ~ 테이블 4 : 손님 테이블 (메뉴 고르고 주문)
  주방 · 카운터        : 테이블별 주문 내용 확인, 메뉴 판매(품절) 설정

[ 주문 흐름 ]
  1. 테이블에서 초밥을 눌러 담고 → [주문하기]
  2. 테이블 화면에 "주문 완료!"가 나와요
  3. 주방 · 카운터 화면에 "띵동!" 소리와 함께 그 테이블 칸에 주문이 바로 떠요
  4. 테이블 화면의 [내 주문]에서 지금까지 주문한 초밥과 합계를 볼 수 있어요
  5. 다 먹으면 테이블 화면의 [🍽️ 다 먹었어요] 버튼을 꾹(1.5초) 눌러요
     → 그 테이블 주문이 비워지고, 주방 · 카운터 화면의 그 테이블 칸도 비워져요
     (살짝 누르면 "꾹 누르고 있어요" 안내만 나오고 비워지지 않아요)
     (주문이 하나도 없을 때는 버튼이 보이지 않아요)
  6. 주문을 취소하고 싶으면 [내 주문]에서 그 주문 상자를 꾹(1.5초) 눌러요
     → 상자가 빨갛게 차오르고, 다 차면 그 주문만 취소돼요


[ 1. 실행하기 ] — 평소처럼 하면 돼요
  ┌───────────────────────────────────────────────┐
  │ cd 바탕화면\sushi-order      ← 압축 푼 폴더 위치로 바꾸세요 │
  │ npm install                                    │
  │ npm start                                      │
  └───────────────────────────────────────────────┘
  ※ 외부 패키지가 하나도 없어서 npm install 은 금방 끝나요 (생략해도 돼요)

  켜지면 cmd 창에 이런 주소들이 나와요 (숫자는 컴퓨터마다 달라요)
     테이블 1        http://192.168.0.10:3000/table/1
     주방 · 카운터   http://192.168.0.10:3000/main


[ 2. 태블릿 연결하기 ]
  - 컴퓨터와 태블릿이 모두 같은 와이파이에 연결되어 있어야 해요
  - 각 태블릿의 크롬에서 cmd 창에 나온 주소로 들어가요
    (또는 http://192.168.0.10:3000/ 로 들어가서 기기를 골라도 돼요)
  - 크롬 메뉴(⋮) → [홈 화면에 추가] 하면 다음부터 아이콘 하나로 열려요
  - 처음에 접속이 안 되면: 윈도우 방화벽 창이 뜰 때 [허용]을 눌러 주세요
  - 주방 · 카운터 화면은 처음에 [시작하기]를 눌러야 소리가 나요


[ 전체화면 · 태블릿 화면 ]
  - 모든 화면 오른쪽 위에 [⛶ 전체화면] 버튼이 있어요 (한 번 더 누르면 꺼져요)
  - 주방 · 카운터 화면은 [시작하기]를 누르면 자동으로 전체화면이 돼요
  - 태블릿을 가로/세로 어느 방향으로 두어도 스크롤 없이 한 화면에 다 보여요
      테이블 화면: 가로는 메뉴 4칸×2줄, 세로는 2칸×4줄
      주방 화면  : 가로는 테이블 4칸 한 줄, 세로는 2칸×2줄
  - 아이폰은 전체화면 기능을 지원하지 않아 버튼이 보이지 않아요
    (안드로이드 태블릿 크롬 · 아이패드에서는 보여요)


[ 3. 주방 · 카운터 화면 ]
  🪑 테이블          테이블 1~4가 스크롤 없이 한 화면에 모두 보여요
                     (가로로 두면 4칸 한 줄, 세로로 두면 2칸×2줄)
                     주문이 들어온 건별로 상자가 나뉘어 최신 주문이 맨 위에 와요
                     (주문번호 · 시간 · 금액 · 초밥 이름과 개수)
                     주문이 많아 칸이 차면 글씨가 조금씩 작아지고,
                     그래도 넘치면 오래된 주문부터 "이전 주문 N건은 접어 두었어요"로 접혀요
                     맨 아래 "주문 금액"은 접힌 주문까지 모두 더한 금액이에요
  🥢 메뉴 판매 설정   스위치를 끄면 테이블 화면에 "오늘은 다 팔렸어요"로 표시 (품절)
                     [초기화하기] → 모든 테이블의 주문 내역을 지우고 #001부터 다시 시작
                                    (품절 설정은 그대로 남아요)


[ 4. 주문 기록 지우기 ]
  손님이 바뀔 때      → 테이블의 [다 먹었어요] 버튼 (그 테이블만 비워져요)
  활동을 새로 시작할 때 → 주방 · 카운터 → 메뉴 판매 설정 → [초기화하기] (전체)


[ 5. 메뉴 · 가격 · 가게 이름 바꾸기 ]
  sushi-order 폴더의 menu.json 을 메모장으로 열어서 고치면 돼요
     "shopName": "꼬마 초밥집"          ← 가게 이름
     { "id": "egg", "name": "계란초밥", "price": 1000, "desc": "달콤하고 폭신한 계란" }
  ※ "id"는 사진 파일 이름과 연결되니 바꾸지 마세요
  ※ 고친 다음에는 Ctrl + C 로 끄고 다시 npm start


[ 6. 메뉴 사진 바꾸기 — "메뉴 사진 다듬기" 화면 ]
  컴퓨터 크롬에서  http://localhost:3000/editor  로 들어가요
  (처음 화면 아래쪽 [🖼️ 메뉴 사진 다듬기] 버튼으로도 들어갈 수 있어요)

  · 왼쪽에서 메뉴를 고르면 보정된 점토 사진이 나와요
  · 분홍으로 덮인 곳 = 지워지는 곳 / 그대로 보이는 곳 = 메뉴 사진으로 남는 곳
  · 🖌 살리기(B) : 칠하면 그 부분이 사진에 남아요
    🧽 지우기(E) : 칠하면 그 부분이 지워져요 (그림자, 배경 등)
    ✋ 이동      : 스페이스바를 누른 채 끌어도 돼요 · 마우스 휠로 확대/축소
    붓 크기      : 슬라이더 또는 [ ] 키
    ↶ 되돌리기   : Ctrl + Z
    👁 원본 보기  : 분홍 표시를 잠깐 끄고 사진만 보기 (V)
  · 오른쪽에 "앱에서 보이는 모습"이 바로바로 나와요
  · [💾 저장하고 앱에 적용] → public\images 에 사진이 들어가고 태블릿에도 바로 바뀌어요
  · [📦 7장 모두 지금 영역으로 저장] → 자동으로 오린 영역 그대로 한꺼번에 적용
  · [↺ 자동으로 오린 영역으로 되돌리기] / [🎨 사진 빼고 기본 그림으로] 도 있어요

  다른 사진을 직접 넣고 싶을 때는 public\images 폴더에 메뉴 id 이름으로 넣어도 돼요
     예) public\images\salmon.png  (이름표는 public\images\README.txt)


[ 7. 효과음 바꾸기 ]
  public\sounds 폴더의 소리 파일을 바꾸면 돼요
     tap.mp3      → 버튼 누를 때
     kitchen.mp3  → 주방 · 카운터에 새 주문이 들어올 때 "띵동"
  다른 이름표는 public\sounds\README.txt 를 보세요
